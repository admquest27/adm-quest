# ADM Quest (site)

Código do jogo web de apoio às aulas do 1º ano do Técnico em Administração. Este repositório é público e contém só código: nenhum dado de aluno, chave ou material do professor.

Comandos:

- `npm install`: instala as dependências.
- `npm run dev`: abre o jogo localmente.
- `npm run build`: gera a versão publicada.

A publicação é automática a cada alteração na branch `main`.
